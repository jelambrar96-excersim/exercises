# 📚 Exercism Solutions Sync

Welcome to my public backup of solutions from [Exercism](https://exercism.org/profiles/jelambrar96)!  
This repository is automatically synced with my Exercism profile, ensuring that all my coding exercises and solutions are safely stored and easily accessible.

---

## 🚀 What is this repository?

This repo contains a **live backup** of all my solutions to programming exercises on Exercism.  
Thanks to the new GitHub Syncer feature, every time I complete an exercise, my solution is automatically uploaded here — no manual scripts or copy-pasting required!

> **Why?**  
> - 🌐 Share progress & learning
> - 💾 Reliable public backup
> - 🔍 Easy to browse and review my solutions
> - 🛠️ Track improvements over time

---

## 🔄 How does the sync work?

- **Automatic Uploads:** Solutions are pushed to this repo via Exercism’s GitHub Syncer.
- **Flexible Configuration:** Choose between Pull Requests or direct commits, and even perform a bulk historic upload.
- **Effortless Management:** No more manual syncing or scripts — everything just works!

## 🛠️ Get Started with Exercism Sync

Want to set up your own sync?
1. Go to your [Exercism profile](https://exercism.org/profiles/jelambrar96)
2. Visit the **GitHub Syncer settings** page
3. Connect your GitHub repo
